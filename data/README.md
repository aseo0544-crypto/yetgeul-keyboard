# 옛말 자료 (data/)

변환 엔진(사전·규칙)을 늘리고 시험하는 데 쓰는 자료 모음입니다.

| 파일 | 내용 | 엔진과의 관계 |
|---|---|---|
| `words.tsv` | 현대어 → 15세기 낱말 대응표 (뜻·출처 포함) | 모든 줄이 `Dict.java`에 들어 있어야 함 (`DataCheck`가 확인) |
| `particles.tsv` | 조사 규칙 표 (조건, 보기, 엔진 적용 여부) | 참고용. "미적용" 줄이 앞으로 만들 규칙 |
| `endings.tsv` | 어미 규칙 표 (같은 형식) | 참고용 |
| `sentences.tsv` | 현대어 문장 ↔ 문헌에 실린 정답 옛말 문장 | `DataCheck`가 변환해서 일치율을 보고 |
| `texts/` | 공유 저작물(15세기 문헌) 원문 + 직접 쓴 현대어 풀이 | 문장 쌍의 근거 |
| `notes/` | 논문·수업 자료에서 뽑은 사실 메모 | 출처만 적고 원문은 옮기지 않음 |

## 표기법

옛말 칸은 `Dict.java`와 같은 표기를 씁니다. `{..}` 안은 호환 자모로 쓴 옛 음절 하나입니다.

- `{ㅎㆍ}` = ᄒᆞ, `{ㅅㆍ}{ㅁㆍㅅ}` = ᄉᆞᄆᆞᆺ, `{ㅎㅗㅭ}` = 홇, `{ㅎㆎ}{ㆀㅕ}` = ᄒᆡᅇᅧ
- 방점은 넣지 않습니다 (엔진이 방점을 자동으로 달지 않으므로).
- 한자는 빼고 원문에 달린 동국정운식 독음을 씁니다 (中듕國귁 → 듕귁).

## 출처 약칭

| 약칭 | 문헌 |
|---|---|
| 훈언 | 훈민정음 언해본 (월인석보 권1 앞, 1459) |
| 용가N | 용비어천가 제N장 (1447) |
| 석상N:쪽 | 석보상절 권N (1447) |
| 월석N:쪽 | 월인석보 권N (1459) |
| 이유기2015 | 이유기, 「석보상절 제9권의 내용과 언어 현상」, 『동악어문학』 65 (2015) — 사용자 제공 PDF |
| 문헌일반 | 여러 15세기 문헌에 두루 나오는 꼴 (표준국어대사전 '옛말' 표제어로 확인 가능) |

15세기 문헌 원문은 저작권이 끝난 공유 저작물입니다. 현대어 풀이는 직접 쓴 것입니다.
논문·교재 같은 저작물에서는 낱말 대응 같은 사실만 뽑고, 문장을 길게 옮기지 않습니다.

## 검사

```powershell
.\test-data.ps1
```

CI(GitHub Actions)에서도 `DataCheck`를 돌립니다. 표기가 잘못되면 실패하고, 문장 일치율은 보고만 합니다.

## 자료 늘리는 방법

1. `words.tsv`에 줄을 더합니다 (탭으로 나눔).
2. 같은 항목을 `Dict.java`의 "자료 모음" 부분에 더합니다.
3. `.\test-data.ps1`로 "사전에 없는 것 0개"와 일치율을 확인합니다.
4. `python windows/gen.py`로 PC 엔진을 다시 만듭니다.
