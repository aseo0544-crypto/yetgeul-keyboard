# 옛글 키보드

문자 앱, 검색창 등 어디서나 한글을 치면 띄어쓸 때마다 **15세기 중세국어 표기**로 바꿔 넣어 주는 안드로이드 키보드입니다.

> 나라의 말씀이 중국과 달라 문자와 서로 통하지 아니하므로
> → 나랏 말ᄊᆞ미 듀ᇰ귁에 달아 문ᄍᆞ와 서르 ᄉᆞᄆᆞᆺ디 아니ᄒᆞᆯᄊᆡ

## 설치
1. [Releases → latest](../../releases/tag/latest)에서 `yetgeul-keyboard.apk`를 폰으로 받아 설치 (출처를 알 수 없는 앱 허용 필요)
2. 앱을 열고 **설정에서 옛글 키보드 켜기** → **옛글 키보드로 바꾸기**

## 쓰는 법
- **[옛]** 키: 변환 켜기/끄기
- 띄어쓰기: 방금 친 낱말을 옛 표기로 바꿈. ⌫를 누르면 원래 글자로 되돌아와 고칠 수 있음
- 후보 줄: 첫 번째는 옛 표기, 두 번째는 "그대로"(바꾸지 않음)
- 길게 누르기: ㅅ→ㅿㅺㅼㅽ, ㅇ→ㆁㆆ, ㅂ→ㅸㅄㅳ, ㅏ·ㅡ→ㆍ
- 기호(!#1) 자판에 방점 〮 〯

## 변환 규칙 (설정에서 하나씩 끌 수 있음)
아래아, 반치음, 옛이응, 순경음 비읍, 합용병서, 이어적기, 8종성, 여린히읗, 옛 문법·말투(합니다→ᄒᆞᄂᆞ이다, 하세요→ᄒᆞ쇼셔, 과 다르다→에 다ᄅᆞ다, 갈 것이다→가리라 등). 사전은 `app/src/main/java/com/yetgeul/keyboard/engine/Dict.java`.

규칙과 사전으로 바꾸는 방식이라 모든 문장이 문법적으로 완벽하지는 않습니다.

## 빌드

- Windows: `.\build.ps1` (JDK 17 + Android SDK), 엔진만 시험: `.\test-engine.ps1`
